## 개선 한 개
짤 저장 파일 이름에 문구 첫 줄을 넣는다. 규칙: `zzal_{제목}_{비율}_{시각}.{확장자}`
- 제목 = 첫 번째 문구의 첫 줄, 앞뒤 공백 제거, 공백은 `_`, 금지 문자 `\ / : * ? " < > |` 제거, 최대 20자, 남는 글자가 없으면 `제목없음`
- 비율 `1:1` → `1x1`, 시각 `YYYYMMDD-HHMMSS`, 확장자 png → `.png`, jpeg → `.jpg`

## 같은 최초 요청 (AI A·B 동일)
> 짤 스튜디오의 저장 파일 이름을 `zzal_{제목}_{비율}_{시각}.{확장자}` 규칙으로 바꾸고, 고정 검사 FN-01~FN-10(`tests/fn-tests.js`)을 모두 통과시켜 주세요. 검사는 삭제·완화·기대값 변경을 하지 않습니다.
